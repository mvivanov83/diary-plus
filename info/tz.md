# ТЗ: электронный дневник частной школы «Дневник+» (MVP)

Источник: реальный заказ FL.ru №5515940 «Разработка веб-сервиса „Электронный дневник частной школы“» (30.07.2026, бюджет по договорённости).
https://www.fl.ru/projects/5515940/razrabotka-veb-servisa-elektronnyiy-dnevnik-chastnoy-shkolyi.html
Заказчик просит оценить отдельно MVP и полный объём. Здесь — MVP. Заказ закрыт, делаем как учебный кейс.

## 1. Задача
Закрытый веб-сервис для частной школы по логике «Дневник.ру», но со своим современным минималистичным дизайном и без мобильных приложений. Всё на русском. Адаптив: компьютер, планшет (учитель заполняет журнал на планшете!), телефон (родитель).

## 2. Роли
- Администратор школы: классы, ученики, учителя, предметы, родители, расписание; модерация регистраций родителей; отчёт по заполнению журнала.
- Учитель: свои уроки по расписанию, электронный журнал, ДЗ, токены, заметки об ученике.
- Родитель: регистрируется сам (e-mail), после одобрения администратором видит своих детей (может быть несколько).

## 3. Экраны администратора
1. Дашборд: учеников / классов / учителей, заявки родителей на модерации, незаполненные уроки за сегодня и вчера, средний балл по классам.
2. Справочники: классы (5А, 6Б…, классный руководитель), ученики (ФИО, класс, родители), учителя (ФИО, предметы), предметы.
3. Расписание: неделя по классу — день, урок №, предмет, учитель, кабинет, время; кнопка «Скопировать неделю на следующую».
4. Родители: заявки «на модерации» → одобрить (привязать к ученику) / отклонить.
5. Отчёт «Заполнение журнала»: по каждому учителю за месяц — уроков всего, заполнено вовремя (до 18:00), с опозданием, не заполнено, % вовремя; экспорт CSV (для расчёта оплаты учителя).

## 4. Экраны учителя
1. Мой день: уроки сегодня; таймер «до 18:00 осталось 2 ч 15 мин»; незаполненные уроки (сегодня и прошлые) — красной меткой «Незаполнен».
2. Журнал урока: тема урока, тип (обычный / контрольная / самостоятельная), посещаемость (присутствовал / отсутствовал / опоздал / уважительная), оценки 2–5 (несколько оценок за урок, у контрольной вес 2), ДЗ (текст + файл), комментарий для родителей.
3. Журнал класса по предмету: сетка ученики × даты, средний балл (взвешенный) и итог за четверть.
4. Карточка ученика: оценки по предметам, средние, посещаемость (% пропусков), история токенов, внутренние заметки учителя (родитель их НЕ видит).
5. Токены: начислить / списать ученику с причиной («активность на уроке», «помощь однокласснику», «опоздание»).

## 5. Правило «до 18:00»
Урок считается заполненным, если отмечены тема и посещаемость. Заполнен до 18:00 дня урока — «вовремя», позже — «с опозданием», не заполнен после 18:00 — статус «Незаполнен» (красный). Напоминание в приложении учителю в 17:00, если есть незаполненные уроки сегодня.

## 6. Экраны родителя
1. Мои дети: переключатель ребёнка.
2. Дневник: расписание на неделю (листание ± 5 недель) с оценками, темами и ДЗ по каждому уроку.
3. Успеваемость: средний балл по предметам, график динамики по неделям, посещаемость.
4. Токены: баланс и история.
5. Уведомления: новая оценка, новое ДЗ, изменение расписания, токены, комментарий учителя.

## 7. Дизайн
Современный минимализм, не копия «Дневник.ру»: фон #F8FAFC, основной #2563EB, акцент #F59E0B, оценки цветом (5 — зелёный, 4 — синий, 3 — жёлтый, 2 — красный), шрифт Inter. Крупные ячейки журнала под палец на планшете.

## 8. Данные (демо)
Школа, 3 класса (5А, 6Б, 7В) по 10 учеников, 5 предметов (математика, русский язык, литература, английский, история), 4 учителя, расписание на текущую неделю ±4 недели, оценки и посещаемость за 4 прошедшие недели, токены. У одного учителя 2 незаполненных урока за вчера (видно «Незаполнен»).
Логины: admin@diary.app / admin123; teacher1@diary.app / teacher123 (математика, классный руководитель 5А); parent1@diary.app / parent123 (двое детей: в 5А и в 7В); одна заявка родителя на модерации.

## 9. Не входит в MVP (следующие этапы по заказу)
Онлайн-оплата через Т-Банк с чеками 54-ФЗ, внутренний мессенджер, новости и объявления, обращения родителей, импорт XLSX/CSV, журнал аудита, Docker и мониторинг, реальная отправка e-mail.

## 10. Критерии готовности
1. Вход под тремя ролями; каждый видит только своё (родитель — только своих детей, учитель — свои уроки).
2. Учитель заполняет урок — оценки и ДЗ сразу видны родителю; средние пересчитываются.
3. Правило 18:00 работает: «вовремя / с опозданием / Незаполнен», отчёт администратора с CSV.
4. Регистрация родителя → модерация администратором → доступ к ребёнку.
5. Токены начисляются и списываются, история видна родителю.
6. Удобно на планшете (журнал) и телефоне (родитель); данные сохраняются после Redeploy.
